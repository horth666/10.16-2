# 测测你是哪种稀有动物人格

一个无需后端、无需安装依赖的静态娱乐测试网站。用户完成 8 道生活情境选择题后，会根据隐藏特征匹配到 12 种动物人格中的一种。

## 本地打开

直接双击根目录的 `index.html` 即可使用。项目没有外部字体、图片、脚本或网络请求。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将本目录中的全部文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main` 和 `/ (root)`，保存即可。

## 文件说明

- `index.html`：页面结构与四个主要状态：首页、答题、揭晓、结果。
- `style.css`：图鉴风格视觉、动效与手机端适配。
- `data.js`：8 道题目、选项分值、12 种动物档案文案。
- `main.js`：答题流程、评分匹配、结果渲染、分享与重新测试。

本项目为娱乐创作，不构成心理诊断。
